# Contributing

感谢你为 RootaAI AI Video Workflow 贡献改进。

## Before opening an issue or pull request

- Describe the user problem and the smallest useful change.
- Keep the workflow brand-neutral except for the maintainer attribution and public project links.
- Do not submit personal data, private projects, API keys, voice profiles, downloaded media, or platform cookies.
- Do not add bundled applications or large model files. Document external dependencies instead.
- For behavior changes, update the relevant tests and run both PowerShell checks in `tests/`.

## Pull requests

Use a clear title, explain the change, list tested commands, and mention any platform or license implications. Documentation, safety, and accessibility improvements are welcome. Keep claims tied to observable behavior.
