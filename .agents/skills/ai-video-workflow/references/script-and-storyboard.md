# Script and Storyboard Method

## Script structures

Use the smallest structure that fulfills the promise.

- Knowledge: `pain/surprise → answer → why it works → steps → example → recap/save`.
- Tutorial: `finished result → prerequisites → action/result pairs → verification → one common failure`.
- Promo: `specific problem → visible transformation → mechanism → proof → next action`.
- Training: `learning objective → rule → demonstration → exception → checklist`.
- Cinematic: `image/sound hook → tension → reveal → evidence → resolved closing line`.

Write spoken Chinese as short sentences. One sentence should normally express one idea and support one subtitle unit. Replace adjectives such as “powerful” or “revolutionary” with a visible action, result, time saved, or limitation.

## From script to shots

Split whenever the viewer's mental task changes. For each segment record:

| Field | Question |
|---|---|
| purpose | Does this shot orient, explain, prove, compare, transition, or create emotion? |
| narration | What exact sentence is heard? |
| screen text | What must be read rather than inferred? |
| visual | What concrete image, UI state, diagram, or action carries the idea? |
| source | User media, licensed stock, screen capture, generated asset, or composition? |
| duration | Is there enough time to understand it without dead air? |
| transition | Why does the next shot replace this one? |
| audio cue | Narration, music change, silence, or sound effect? |

## Information density

- A mobile title card: one headline plus at most one supporting line.
- Keep spoken explanation out of dense on-screen paragraphs.
- Let proof remain longer than decoration; speed through waiting, downloads, and repeated clicks.
- Use callouts only on the item being discussed.

## Cheap-looking failure patterns

- Unrelated skyline/server footage under every technology claim.
- Five different transition styles in one minute.
- Constant zoom, glow, particles, or glitch effects with no narrative reason.
- Stock clips with mismatched color, era, aspect ratio, or lighting.
- An AI voice reading long written prose without conversational pauses.
- Claims that the screen never demonstrates.
- A logo appearing more often than the viewer receives value.
