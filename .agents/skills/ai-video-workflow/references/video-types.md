# Video Type Selector

Choose by viewer outcome and available proof, not by the most fashionable tool.

| Type | Best when | Reliable structure | Visual proof | Main risk |
|---|---|---|---|---|
| Knowledge explainer | The viewer wants a useful idea quickly | pain or surprise → answer → 3 steps → example → save prompt | diagrams, examples, before/after, highlighted evidence | abstract narration over unrelated stock |
| Software tutorial | The viewer wants to complete a task | result first → prerequisites → exact actions → verification → common error | readable screen capture, cursor focus, input/result pairs | showing every click at real speed |
| Product or service promo | The viewer must understand value and trust it | problem → visible result → how it works → proof → next action | product UI, real output, workflow, measured claim | slogan-heavy footage with no demonstration |
| Training or internal video | Accuracy and repeatability matter | objective → rule → demonstration → exception → checklist | process map, annotated recording, correct/incorrect comparison | dense slides and long paragraphs |
| Cinematic faceless montage | Emotion and identity lead, while a real message remains | visual hook → tension → reveal → method/proof → branded close | purposeful motion, sound design, recurring visual motif | becoming a generic stock-library advertisement |

## Recommendation rule

- Has a real interface or procedure: prefer software tutorial or training.
- Has a strong idea but little footage: prefer knowledge explainer with motion graphics.
- Has product proof and a desired action: prefer product promo.
- Has premium clips or generated motion and an emotional promise: consider cinematic montage.
- If evidence is thin, reduce claims before increasing spectacle.

## Faceless retention rules

- Put the result or tension in the first 1–3 seconds.
- Change visual state every 2–4 seconds: shot, crop, annotation, text hierarchy, or motion—not random decoration.
- Alternate context, detail, and proof shots. A shot must explain, prove, orient, transition, or create emotion.
- Give viewers something worth saving: a repeatable method, checklist, parameter, template, or failure warning.
- End with one next action. Do not stack follow, like, comment, buy, and share in the same close.
