# Assets and Licensing

## Search from shot purpose

Search for observable action, setting, camera behavior, mood, and format. Example: `hands editing timeline close-up slow push-in vertical`, not merely `technology`.

Prefer, in order:

1. User-owned footage, recordings, screenshots, and product output.
2. Assets whose license explicitly permits the intended publication and modification.
3. AI-generated assets with recorded provider, model, prompt, date, and usage terms.
4. Decorative stock only when it supports a defined shot purpose.

Do not require Google services. Ask about the user's region and accessible providers, then use OpenMontage's live registry rather than assuming a service is available.

## Required provenance record

For every external asset record:

- local filename and scene ID;
- source URL or provider job ID;
- creator/provider;
- license name or usage terms;
- retrieval/generation date;
- modification and commercial-use status;
- attribution text if required;
- notes about people, trademarks, private data, or synthetic media.

Do not download from YouTube, TikTok, or another creator merely because a downloader works. Use only material the user owns, has permission to reuse, or is using within a documented lawful exception. A reference video may guide analysis; it is not automatically reusable footage.

## Selection check

- Inspect resolution, fps, duration, compression, orientation, and safe crop.
- Preview faces, hands, text, logos, and generated artifacts at full size.
- Reject clips that duplicate the same visual idea.
- Normalize color and motion only after the sequence is approved.
- Keep originals untouched; derived media goes in the project workspace.
